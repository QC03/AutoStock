# Frontend (Next.js)

AutoStock 6단계 프론트엔드 구현입니다.

## 포함 기능

- Next.js + TypeScript + Tailwind CSS 초기화
- 로그인 / 회원가입 페이지
- 대시보드 (포트폴리오/거래 지표)
- 종목 상세 페이지 (실시간 시세 차트 + AI 신호 표시)
- 매매 설정 페이지 (자동매매 ON/OFF)
- 매매 내역 페이지
- Axios + React Query API 연동

## 실행

```powershell
cd frontend
npm install
npm run dev
```

기본 API 주소는 `.env.example` 참고 (`NEXT_PUBLIC_API_BASE_URL`).
